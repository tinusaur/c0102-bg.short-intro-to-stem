# Кратък увод в STEM

Кратък примерен курс за STEM като един начин на мислене, за учащи. Това е **българското издание** на `C0102`. Съпътстващ наръчник **`C0202`** (същите уроци и теми). Съпътстващи слайдове **`C0602`** (българското издание).

**Аудитории:** Начинаещи читатели и по-млади читатели.
